# Security policy

## Supported versions

| Version | Frappe / ERPNext | Supported |
|---|---|---|
| 0.0.x | v15, v16 | Yes |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/thinkspedia/frappe_psak_id/security/advisories/new)). Include the PSAK ID, Frappe and ERPNext versions, the steps to reproduce, and the impact you expect.

We will acknowledge the report and agree on a fix and disclosure timeline with you.

## Scope notes

- PSAK ID presents financial statements. Any way to read ledger figures of a company, or a period, that the user's ERPNext permissions do not allow is a vulnerability.
